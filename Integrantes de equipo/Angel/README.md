# Aportación individual — Videos 06 y 07 de NumPy


## Contenido
- `notebooks/06_funciones_basicas_matrices.ipynb`: funciones y propiedades básicas de arreglos/matrices.
- `notebooks/07_operaciones_basicas_matrices.ipynb`: operaciones básicas con matrices.

## Instalación
Desde la carpeta de esta aportación, crea y activa un entorno virtual e instala las dependencias:

```bash
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
```

Abre los notebooks en Visual Studio Code con las extensiones Python y Jupyter y ejecuta las celdas en orden.

## Nota
Los notebooks son una base de trabajo sobre los temas asignados. Antes de entregar, verifica los ejemplos y completa los ejercicios exactamente como aparecen en los videos.
