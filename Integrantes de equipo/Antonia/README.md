# Aportación de Antonia Martínez Santos: videos 08 y 09

Ejercicios del curso de NumPy de Yacklyon. Esta carpeta es una aportación individual para integrarse al repositorio del equipo; no sustituye la entrega de los demás integrantes.

## Contenido
- `notebooks/08_numeros_aleatorios.ipynb`
- `notebooks/09_ejes_matrices.ipynb`

## Ejecución
En una computadora con Python, desde esta carpeta:
```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
# source .venv/bin/activate
python -m pip install -r requirements.txt
python -m jupyterlab
```
No requiere datasets externos.

## Integración al equipo
Crear la rama `feat/ejercicios-videos-08-09`, copiar los notebooks a `notebooks/` del repositorio compartido, hacer commits descriptivos y abrir un Pull Request. Otro integrante debe revisarlo y comentarlo antes de integrarlo a `main`. No subir esta carpeta completa a `main`.

## Validación
Todas las celdas se ejecutaron en orden con Python 3.13 y NumPy 2.3. Las salidas están guardadas en los notebooks. Falta la prueba de clonado e integración del repositorio completo del equipo.

## Fuente
Videos “CURSO DE NUMPY BASICO · como usar los números aleatorios” e “implementar ejes a las matrices”, canal Yacklyon. El código es el que presentó la integrante en sus audios; se agregaron un título y comentarios explicativos en cada notebook.
